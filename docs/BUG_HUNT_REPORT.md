## BUGS NOT REPORTED BY USER

These were discovered during adversarial review rather than copied from the user checklist.

- **Vertical stacking gap (BH-022):** interactive clutter required a contact axis the earlier solver did not have.
- **Material-audio mismatch (BH-024):** adding glass/ceramic/cardboard without extending the audio system produced generic feedback.
- **Decorative-vs-physical environment split (BH-019):** visually rich props were not automatically part of the collision world.
- **Renderer segment mismatch (BH-025):** topology could be mathematically valid while still looking visibly too coarse for hero assets.
- **QA risk:** a green legacy regression is not evidence for V2; all gates were repointed to the new active modules before the first V2 PR run.
