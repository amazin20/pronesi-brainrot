## BUGS NOT REPORTED BY USER

These were discovered during adversarial review rather than copied from the user checklist.

- **Vertical stacking gap (BH-022):** interactive clutter required a contact axis the earlier solver did not have.
- **Material-audio mismatch (BH-024):** adding glass/ceramic/cardboard without extending the audio system produced generic feedback.
- **Decorative-vs-physical environment split (BH-019):** visually rich props were not automatically part of the collision world.
- **Renderer segment mismatch (BH-025):** topology could be mathematically valid while still looking visibly too coarse for hero assets.
- **Deferred destruction iteration bug (BH-034):** immediate splicing was unsafe even though simple break tests passed.
- **Floor-impact damage gap (BH-035):** body/body impacts and base-floor impacts followed different paths.
- **Low-wall floor classification (BH-036):** an old convenience heuristic changed actual collision semantics.
- **Broad-phase performance gap (BH-032):** sleeping alone did not remove the all-pairs candidate generation cost.
- **Mobile QA coverage gap (BH-037):** shared math tests were not evidence that pointer capture/event routing worked.
- **Static-theme override bug (BH-038):** valid geometry could still look like a broken giant slab because a default color defeated theme fallback.
- **QA risk:** green tests are not accepted until their screenshots and exact active runtime are manually inspected.
